Telltale

開源 Flutter OBD2 車輛遙測與診斷

繁體中文 English

Telltale 透過 ELM327 相容轉接器讀取即時車輛資料與 OBD2 故障資訊，並在資料不完整或互相衝突時明確顯示不確定。

一個看起來合理的錯數字，比沒有數字更糟。

連線方式

  • Bluetooth Classic / RFCOMM（僅 Android）
  • Bluetooth LE / GATT
  • Wi-Fi / TCP
  • 內建 Demo ECU

Android 是目前主要完成實體裝置、UI 與 BLE 測試馬具驗證的平台；iOS 與 macOS 只有編譯閘門，不能視為已完成實機或實車驗證。

從 GitHub Releases 下載 APK 從 Google Play 安裝 查看原始碼

Google Play 版為付費下載，但同版本的功能與原始碼、社群 APK 相同，沒有付費解鎖項目。購買相當於支持持續維護，也省去自行建置、安裝與管理更新；願意自行 build 的使用者仍可免費使用原始碼或 GitHub APK。

安裝前注意：GitHub APK 使用社群簽章，無法更新 Google Play 版，Play 版也無法直接更新它。兩者互換必須先解除安裝，會刪除 App 本機資料；請先匯出需要保留的診斷紀錄並記下設定。

實驗性動力電池資料實驗室

資料目錄包含 221 個有來源依據的 PHEV、HEV、BEV、MHEV、REEV 與 FCEV profile：205 個僅供研究；12 個是可安裝的跨來源社群 profile（MG ZS EV Mk1、MG4 Electric、MG5 EV、BYD Atto 3、Hyundai Ioniq 5 與 Ioniq 6、Kia EV6、Hyundai Kona Electric、Kia Niro EV、Kia Soul EV、Renault Zoe Ph1、VW e-up! gen2——每條公式都經至少兩個獨立實作逐 byte 比對，安裝時需確認車輛身分，且每次連線都要重新確認才會開始唯讀輪詢）；4 個是只能走預設關閉之實驗室的實驗 profile（含 Kia EV9 與 Toyota bZ4X／Subaru Solterra e-TNGA）。實驗室的每次連線與嘗試都需要短效、一次性的明確同意，只送出一個固定的唯讀指令；不掃描識別碼、不批次送出、不自動重試。任何結構不符的回應都會顯示為故障而不是數字。詳見 動力電池 profile、證據與安全邊界。

目前的驗證邊界

已驗證：Samsung 實體手機到 Mac 的真實 BLE/GATT 無線路徑，搭配模擬 ELM327，已完成掃描、連線、UART 寫入與通知。另有一組 Samsung、CL-OBDII-M25B 與 Toyota GT86 的實車觀察和保留的 session 紀錄；保留下來的怠速輪詢片段使用 CAN 11-bit / 500 kbit/s，未出現 NO DATA、CAN/BUS 錯誤、逾時或格式錯誤回覆。

仍未證明：這項單一觀察不等於轉接器韌體、PID 準確性、DTC 完整性、負載行駛或一般 GT86 支援的認證。它也不能證明其他轉接器、ECU/BMS，或目錄中的 PHEV 與其他動力電池 profile 會提供相同 PID、比例或 payload。

請只在車輛停妥時操作，或交由乘客操作。清除 DTC 前先保存診斷證據。App 不會主動上傳資料；你匯出的紀錄可能含 VIN、裝置與轉接器識別資訊。
